# Minesweeper Web Game

A browser-based Minesweeper game built with HTML, CSS, and JavaScript. The project recreates the classic Minesweeper game with difficulty levels, random mine placement, tile reveal logic, flagging, a timer, and a local leaderboard.

## Live Demo

[View Live Demo](https://minesweeper-web-game.vercel.app/)

## Features

- Interactive Minesweeper game board
- Easy, Medium, and Hard difficulty levels
- Random mine placement for each game
- Tile reveal logic with neighbouring mine counts
- Right-click flagging for suspected mines
- Win/loss detection
- Game timer
- Reset board option
- Rules page and in-game “How to play” popup
- Signup and login system using localStorage
- Leaderboard storing top scores by difficulty

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage
